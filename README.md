# ⚖️ 제일기획 AX대회 출품작 — 「견적감독관 (Estimate Auditor)」

> **"제작비 견적의 근거를 분해하고, 광고주 컨펌 기준과 대조하며, 질의에 대한 소명 답변을 증빙하는 AI 감리 에이전트"**

---

## 1. 프로젝트 개요

전시 제작 및 키트/콘텐츠 제작 프로젝트에서 변경 견적이 발생할 때, **광고주 컨펌 완료 기준 견적서**와 변경 내역을 대조하여:
1. **제작비 차이 요인 분해**: 수량 효과와 단가 효과를 수학적으로 분해하여 “왜 비싼가”를 자동 설명.
2. **설치/철거 투입률 검토**: 1인 1일 투입률 100% 초과(집중 야간 셋업) 공정 자동 탐지.
3. **원형 개발 공정 소명**: 디자인 5.0일 투입에 대해 5단계(시안, 3D 모델링, 렌더링, CMF, 제작 감리) 분해 및 RACI 역할 분장 소명.
4. **광고주 91건 FAQ 소명서 자동 생성**: “이 금액이 왜 이 금액인가요?” 질의에 대해 출처와 산출식이 첨부된 공문형 답변을 1초 만에 완성.
5. **수량 × 단가 재계산 원칙**: 모든 합계와 차이는 파이썬 코드로 검증하며, AI 계산 오류 없이 투명한 신호등(🟢/🟡/🔴) 판정을 제공합니다.

## 3. 핵심 기능 (AX대회 4대 모듈)

- **🚦 탭 1: 신호등 감리 리포트**: 🟢 적정 (승인 완료), 🟡 확인 필요 (연결 불확실), 🔴 과다/반려 (반려 반영 또는 승인 누락)
- **🧩 탭 2: 제작비 요인 분해**: `(수량2 - 수량1) × 단가1` + `(단가2 - 단가1) × 수량2` = `차이금액` 완전 일치 보장
- **👷 탭 3: 설치/철거 투입률 검토**: 투입률 100% 초과 탐지 및 야간 셋업 할증 타당성 검토
- **💬 탭 4: 광고주 질의 대응 (91건 FAQ)**: 단골 질의 선택 시 공문형 소명 답변서 즉시 생성
- **🔗 탭 5: 연결 확인**: 유사도 기반 후보에 대한 사용자 대화형 확정
- **📄 탭 6: 원본 대조 & CSV 내보내기**: `utf-8-sig` 인코딩 및 원본 행(`파일명 / 시트 / 행`) 추적
